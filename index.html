一、核心概念：三层扩展体系


Marketplace（市场）  →  插件的注册表/索引（类比：npm registry、VS Code Marketplace）
    ↓
Plugin（插件）       →  安装的最小单位（自包含目录，可版本化、可分发）
    ↓
Skill / Agent / Hook / MCP Server / Command（具体能力）

**一句话理解：** 市场告诉你"有什么插件可用"，插件是"一包功能"，装好插件后里面带着各种 skills（技能）、agents（子代理）、hooks（钩子）、MCP server')" title="点击查看解释">MCP servers（外部工具连接）。

层类比本质
Marketplace应用商店一个 GitHub 仓库，根目录有 `.claude-plugin/marketplace.json`
Plugin一个App自包含目录 + `.claude-plugin/plugin.json` 清单
SkillApp里的一个功能最小能力单元（markdown 指令文件）

二、基本语法：CLI 命令

启动与会话


claude                      # 交互式启动
claude "query"              # 直接提问（打印模式）
claude -p "query"           # 打印模式（-p = --print）
claude --continue / -c      # 继续当前目录最近的会话
claude --resume <id>        # 恢复指定会话
claude --resume             # 从列表中选择恢复
claude --fork-session       # 恢复时创建新会话ID（配合 --resume/--continue）

会话管理


claude attach <id>          # 附加到后台会话
claude logs <id>            # 打印后台会话最近输出
claude stop <id>            # 停止后台会话（别名 claude kill）
claude rm <id>              # 删除会话（记录保留，可用 --resume 找回）
claude respawn <id>         # 重启会话保持对话完整
claude daemon status        # 查看后台会话supervisor状态
claude daemon stop --any    # 停止supervisor
claude doctor               # 打印安装/设置诊断

插件与MCP


claude plugin install github@claude-plugins-official   # 安装插件
claude plugin list          # 列出插件
claude plugin prune         # 清理未使用插件
claude plugin validate      # 校验插件JSON
claude plugin marketplace add <repo>   # 添加市场
claude mcp                  # 配置 MCP 服务器
claude mcp login <name>     # MCP OAuth登录

其他常用


claude project purge [path] # 清除项目本地状态（--dry-run预览）
claude setup-token          # 为CI生成长期OAuth令牌
claude ultrareview [target] # 非交互运行代码审查（--json）
claude --bg "task"          # 后台代理模式
claude --exec 'pytest -x'   # 作为后台作业运行shell命令

常用 CLI 标志


--add-dir <dir>                 # 添加额外工作目录
--agent <name>                  # 指定代理
--allowedTools "Bash(git *)"    # 免提示权限的工具（模式匹配）
--disallowedTools "Edit"        # 拒绝的工具
--dangerously-skip-permissions  # 跳过所有权限提示（等于 bypassPermissions 模式）
--append-system-prompt "..."    # 追加系统提示词
--append-system-prompt-file ./rules.txt
--max-turns 3                   # 限制代理轮数（打印模式）
--max-budget-usd 5.00           # 预算上限
--output-format json|stream-json  # 输出格式
--json-schema '{"type":"object"}' # 结构化JSON输出
--effort high                   # 工作量级别 low/medium/high/xhigh/max
--fallback-model sonnet,haiku   # 模型回退链
--model <model>                 # 指定模型
--permission-mode <mode>        # 权限模式
--print/-p                      # 打印模式
--continue/-c                   # 继续会话
--debug                         # 调试模式
--init                          # 运行setup hooks
--bare                          # 极简模式（跳过skills/plugins/MCP等发现）
--ide                           # 自动连接IDE

四、快捷键（keybindings）

**配置文件：** `~/.claude/keybindings.json')" title="点击查看解释">keybindings.json`（运行 `keybindings')" title="点击查看解释">/keybindings` 创建/打开）

**热重载：** 修改自动生效，无需重启

默认快捷键速查

快捷键操作
`Ctrl+C`取消当前操作（app:interrupt）
`Ctrl+D`退出 Claude Code（app:exit）
`Ctrl+T`切换待办清单（app:toggleTodos）
`Ctrl+O`切换详细记录（app:toggleTranscript）
`Ctrl+R`打开历史搜索（history:search）
`↑` / `↓`上一条/下一条历史（history:previous/next）
`Esc`取消当前输入（chat:cancel）
`Ctrl+L`强制全屏重绘保留输入（chat:clearInput）
`Shift+Tab`循环权限模式（chat:cycleMode）
`Ctrl+X Ctrl+K`终止所有后台子代理（chat:killAgents）

自定义快捷键示例


{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "ctrl+u": null
      }
    }
  ]
}

**快捷键命名规范：** `小写修饰符+键`，如 `ctrl+shift+p`、`meta+p`（Windows/Linux 用 `ctrl`，macOS 用 `meta`）

五、插件体系详解

5.1 市场如何工作（两步走）

1. **添加市场**（注册目录，可浏览）

2. **安装单个插件**（从目录中选择下载）

类比：添加应用商店 → 商店可见 → 从中选应用下载。

5.2 官方市场（自动可用，无需添加！）

  • 市场名：`claude-plugins-official`
  • 启动 Claude Code 后自动可用
  • 浏览：运行 `/plugin` 进入"发现"选项卡，或访问 claude.com/plugins
  • 安装：`/plugin install <name>@claude-plugins-official`

    • 5.3 添加社区市场

    
/plugin marketplace add <github-owner>/<repo>
/plugin marketplace add https://github.com/xxx/yyy   # 完整URL也可
/plugin marketplace list      # 查看已添加市场
/plugin marketplace remove <name>   # 移除市场
/plugin marketplace update    # 更新市场目录

    5.4 插件安装全流程

    
/plugin                          # 打开插件管理菜单
/plugin install <name>@<market>  # 安装：/plugin install github@claude-plugins-official
/reload-plugins                  # 刷新使插件生效
/plugin list                     # 验证已安装
/plugin update <name>            # 更新插件
/plugin disable <name>           # 禁用插件

    5.5 插件本地位置（Windows）

    
C:\Users\<用户名>\.claude\plugins\

    手动安装：把插件目录/zip放到这里。

    六、创建自己的插件（快速开始）

    
my-first-plugin/
├── .claude-plugin/
│   └── plugin.json      # 插件清单（名称/描述/版本）
└── skills/
    └── hello/
        └── SKILL.md     # skill定义

    **plugin.json 示例：**

    
{
  "name": "my-first-plugin",
  "description": "我的第一个插件",
  "version": "1.0.0"
}

    **测试：**

    
claude --plugin-dir ./my-first-plugin
# 然后运行 /hello 测试skill

    **独立配置 vs 插件对比：**

    方法Skill名称适合
    独立（`.claude/`目录）`/hello`个人工作流、快速实验
    插件（自包含目录）`/plugin-name:hello`团队共享、社区分发、版本化

    **建议流程：** 先在 `.claude/` 独立配置快速迭代 → 稳定后转成插件分发。

    七、Skill / Agent / Hook / MCP 快速认知

    Skill（技能）

  • 最小能力单元，本质是 markdown 指令文件（SKILL.md）
  • 位置：`~/.claude/skills/` 或插件内 `skills/` 目录
  • 通过 `/skill-name` 调用或自动触发

    • Agent / Subagent（子代理）

  • 独立配置的专用代理，带自己的 system prompt
  • 创建：`/agents create` 或 `.claude/agents/` 目录
  • 前台/后台运行：`/agents` 或 `Ctrl+X Ctrl+K` 终止

    • Hook（钩子）

  • 在事件（SessionStart、PreToolUse、PostToolUse等）触发时执行脚本
  • 配置：`.claude/settings.json` 或 `/hooks`
  • 参考文档：`md/hooks.md`（207KB，内容最详实）

    • MCP Server（外部工具连接）

  • Model Context Protocol，连接外部工具/数据源
  • 配置：`claude mcp add <name> <command>` 或 `/mcp`
  • 参考文档：`md/mcp.md`、`md/mcp-quickstart.md`

    • ---

    八、给新手的学习路径建议

    1. **读**：本文档 + `md/overview.md` + `md/how-claude-code-works.md`

    2. **用**：敲 `/plugin marketplace list` 看看官方市场（你之前用了一个月都不知道它默认存在！）

    3. **试**：从官方市场装 1-2 个插件，观察它往 `~/.claude/plugins/` 里放了什么

    4. **抄**：把官方插件源码当教材读（anthropics/claude-plugins-official）

    5. **造**：照着第六节模板做一个自己的玩具插件，跑通一次全懂了
